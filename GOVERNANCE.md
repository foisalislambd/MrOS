# Governance

MrOS is maintained by [@foisalislambd](https://github.com/foisalislambd).

## Decision making

- Day-to-day changes: maintainer review via pull requests
- Breaking changes / roadmap shifts: discussed in issues or discussions before merge
- Security process: see [SECURITY.md](./SECURITY.md)

## Becoming a maintainer

Regular, high-quality contributions and community help may lead to maintainer
invites. There is no formal application form yet — open an issue if you want to
help steward the project long-term.
